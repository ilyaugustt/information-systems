# Диаграммы бизнес-процессов (BPMN)

## AS-IS — Текущий процесс модерации

**Описание:** Модераторы вручную просматривают выборочные комментарии. Охват < 1% от ежедневного потока. Процесс медленный, субъективный и не масштабируемый.

```mermaid
flowchart TD
    A([Пользователь публикует комментарий]) --> B[Комментарий появляется в ленте]
    B --> C{Случайная выборка\nмодератора}
    C -- Не выбран\n~99% --> D[Комментарий остаётся без проверки]
    C -- Выбран\n~1% --> E[Модератор читает комментарий вручную]
    E --> F{Нарушение?}
    F -- Нет --> G[Комментарий одобрен]
    F -- Да --> H[Модератор блокирует комментарий]
    H --> I[Составление отчёта вручную]
    I --> J([Отчёт в РКН — с задержкой])
    D --> K([Потенциальное нарушение\nне замечено → риск штрафа])
```

**Ключевые проблемы AS-IS:**
- Охват 1% → 99% комментариев не проверяются.
- Задержка реакции: часы–дни.
- Нет аналитики тональности для бизнеса.
- Субъективность: разные модераторы принимают разные решения.

---

## TO-BE — Процесс с ML-системой

**Описание:** ML-система обрабатывает 100% комментариев в реальном времени. Модераторы работают только с пограничными случаями. Нарушения блокируются автоматически с логированием для РКН.

```mermaid
flowchart TD
    A([Пользователь публикует комментарий]) --> B[API Gateway принимает комментарий]
    B --> C[Kafka: топик comments.raw]
    C --> D[ML Inference Service\nRuBERT модель]
    D --> E{Decision Engine:\nviolation_score}

    E -- score > 0.7\nАвтоблокировка --> F[Action Service:\nкомментарий заблокирован]
    E -- score 0.5–0.7\nГраничный случай --> G[Очередь на ручную проверку]
    E -- score < 0.5\nАвтоодобрение --> H[Комментарий опубликован]

    G --> I[Модератор проверяет\nчерез Web UI]
    I --> J{Решение\nмодератора}
    J -- Блокировать --> F
    J -- Одобрить --> H

    F --> K[Audit Log: ClickHouse\nлог решения + причина]
    H --> K
    K --> L([Автоотчёт в РКН\nпо расписанию])
    K --> M([Дашборд тональности\nдля бизнеса])

    D --> N[Feature Store:\nобновление истории пользователя]
    J --> O[Разметка: Human-in-the-loop\nдля переобучения модели]
```

**Что меняет ML-система:**

| Аспект | AS-IS | TO-BE |
|---|---|---|
| Охват проверки | 1% | 100% |
| Скорость решения | часы | < 500 мс |
| Нагрузка на модераторов | 100% комментариев | только пограничные (5–10%) |
| Отчётность для РКН | ручная, с задержкой | автоматическая, в реальном времени |
| Аналитика тональности | отсутствует | дашборд в реальном времени |
